# Architecture Decision Records (ADRs)

This directory contains records of the architecturally significant decisions made during the design and development of TaskFlow.

## What is an ADR?
An Architecture Decision Record captures an important architectural choice made along with its context and consequences.

## Format
Each record follows the standard Michael Nygard template:
- **Title**: Number and brief title (e.g., `0001-record-architecture-decisions.md`)
- **Status**: Proposed, Accepted, Deprecated, Superseded
- **Context**: The problem or design challenge being addressed
- **Decision**: The architectural choice made
- **Consequences**: Positive and negative tradeoffs resulting from the decision
